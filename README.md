# LDD_assignments
Linux Device Drivers assignments, character device examples, ioctl, timers, workqueues, and module parameter exercises.

## Purpose

Educational collection of Linux kernel character device driver exercises used for learning core LDD concepts: module init/exit, `cdev`, circular buffers, `ioctl`, waitqueues, timers, workqueues, module parameters, and exported symbols.

## Contents

- Each top-level folder is an assignment/module and typically contains a kernel module (`*.c` / `*.ko`), a `Makefile`, and user-space test programs (e.g., `user_read.c`, `user_write.c`, `test.c`).
- Key folders: `Helloworld`, `char_device`, `ioctl`, `kernal_timers`, `wq_chardevice`, `module_param`, `multiple_devices`, `export_mod_sym`, `cdevice`.

## Build

Build modules per-folder. Example:

```sh
cd <module-folder>
make
```

## Install / Test (example)

As root:

```sh
sudo insmod <module>.ko
# check dmesg for allocated major/minor
sudo mknod /dev/<name> c <major> <minor>
./user_read   # or ./user_write / ./test as provided
sudo rmmod <module>
dmesg -w
```

## Notes

- Some examples use static major/minor numbers in code; confirm device numbers in source or kernel output before creating device nodes.
- Files named `*.mod.c` are build artifacts generated by the kernel build system and can be ignored.
